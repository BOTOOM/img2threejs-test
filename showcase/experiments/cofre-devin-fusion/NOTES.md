# cofre devin fusión

Procedural crown chest rebuilt from a single reference image with `img2threejs` v1.5-beta
(skill commit `d6673386f89673a58736f8d398dd16ece67874f5`). Source project and full pass history:
https://github.com/BOTOOM/cofre3d/pull/1

## What is in this folder

| File | Role |
| --- | --- |
| `ref.png` | The only input to the reconstruction. |
| `render.png` | Final procedural hero render (same camera as the comparator). |
| `demo.html` + `assets/` + `pbr/` | Bundled interactive scene built from the TypeScript factory. |
| `cofre.glb` | TRELLIS image-to-mesh output — render baseline only. |
| `glb-viewer.html` | The GLB on its own, for orbit inspection. |
| `compare.html` | Image vs result wipe, and GLB vs result live overlay. |
| `src/createChestModel.ts` | Generated factory (authored via `author_spec.py`, never hand-edited). |
| `object-sculpt-spec.json` | Sculpt spec that passes `validate_sculpt_spec.py --strict-quality` with `RC=0`. |

## TRELLIS is a baseline, not a source

`cofre.glb` was generated by uploading `ref.png` to the public `trellis-community/TRELLIS`
Space. It is a single mesh with a single material (14 936 vertices, 21 304 triangles, not
watertight). No geometry, topology, UV or material from it feeds the procedural factory: the
model is built entirely from Three.js primitives in code. The GLB exists here so the recovered
silhouette can be read against an independent image-to-mesh reconstruction.

## Fidelity

Tier-1 render diagnosis on the hero view: silhouette IoU 0.8945, aspect-ratio delta 0.0205,
scale delta 0.0024, bilateral symmetry error 0.0742, no failures. Eight orbit views were
checked and none is degenerate.

## Inferred regions

The reference shows a single three-quarter view, so the following were inferred rather than
observed: the rear panel and its ironwork, the underside of the plinth, the chest interior and
lid inner face, the hinge barrel geometry, and the far-side hardware, which is mirrored from
the visible side.
